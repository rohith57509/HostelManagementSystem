# Hostel Management System
Full-stack college project: React + Spring Boot + MySQL + JWT.

## Run backend
1. Edit backend/src/main/resources/application.properties and set your MySQL password.
2. cd backend
3. .\mvnw.cmd clean compile
4. .\mvnw.cmd spring-boot:run
Backend: http://localhost:8080

## Run frontend
1. cd frontend
2. npm install
3. npm run dev
Frontend: http://localhost:5173
